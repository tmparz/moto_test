# 機車駕照模擬練習網站

以使用者提供的 **115.1 版《機車駕照筆試題庫》** PDF 製作的純前端網站。

## 功能
- 從 **806 題**隨機抽取 **50 題**，無重複（錯題模式依錯題數最多取 50 題）。
- **每次開始測驗，每題的三個選項都重新隨機排列**，評分以原始正確選項索引為準，不會被洗牌影響。
- 全部 50 題作答後才可交卷，100 分制（每題 2 分）。
- 完整訂正、過往錯題練習、最佳成績、瀏覽器本機儲存未完成試卷。
- 題庫中的交通標誌/圖片題已從 PDF 擷取，並以 WebP 內嵌在資料中。
- 手機與桌機皆可使用，零後端／零 build／免 API 金鑰。

## 使用與部署

打開 `index.html` 即可使用。部署到 GitHub Pages：到 Settings > Pages > Build and deployment > Deploy from a branch，選擇 `main` + `/ (root)`，儲存後即可從 `https://tmparz.github.io/moto_test/` 開啟。

題目都在 `data/part-01.js` 到 `data/part-09.js`，`window.MOTO_DATA.push(...[...])` 會累加所有題目。

## 注意

原 PDF 檔名標示「804 題」，**實際頁面題號由 1 到 806**，網站完整收錄全部 806 題。題目與答案照原 PDF 內容收錄，不代表官方正式考場抽題與計分機制。
